## Core Systems Tutorial Repository

This is the code repository for the Core Systems (Items, Interaction, and Inventory) video tutorial series for Unreal Engine 5 C++.  

The series playlist can be found at the following link:  
https://www.youtube.com/watch?v=cPgtd4m5-EI&list=PLitYOdh3OOzhJBCRqYZEGBzJYemA-SH8Z

Any assets such as blueprints, data tables, etc. created specifically for the project 
are versioned and are located at Content/CSTutorial.

External content packages will not be added to version control due to how they can easily bloat the project size to a ridiculous level.
However, I will never add a package to this project that is not free, so that way you can always easily add whatever is missing from the UE Marketplace.

Note (July 2025): Unfortunately, it looks like during the transition from the old UE Marketplace over to "Fab", Epic chose to stop hosting the free Infinity Blade assets. What a shame... if you already owned them in your library, you should still be able to download and use them, but it looks like I'm going to be using placeholders until I can find a good and free replacement prop pack.
